# 미션팡 캐릭터·장비 제작 규격 (고정)

이 문서의 수치는 **고정 규격**이다. 캐릭터·장비 아트를 새로 만들 때 반드시 따른다.

## 1. 캔버스 규격 (모든 캐릭터·장비 공통)

| 항목 | 값 |
|---|---|
| 캔버스 | **1024 × 1024**, 투명 배경 |
| 저장 포맷 | 투명 PNG로 제작 → 앱 탑재 시 고화질 투명 WebP 변환 |
| 발바닥 기준선 | **y = 940** |
| 몸통 중심 | **x = 512** |
| 머리 중심 | **(512, 285)** |
| 전체 키 | **820px** (머리 위 y = 120) |
| 얼굴 방향 | 정면 고정 |
| 포즈 | 양팔 내린 좌우 대칭 정자세 고정 |

## 2. 장비 제작 방식 (레이어 방식)

- 장비만 작게 잘라 저장하지 **않는다**.
- 캐릭터와 **동일한 1024×1024 캔버스**를 쓰고, 장비를 착용 위치에 놓은 뒤
  나머지 영역은 투명으로 저장한다.
- 앱은 캐릭터·장비 이미지를 **100% 크기로 그대로 겹쳐** 표시한다.
  (슬롯별 위치 보정 코드 없음 — AvatarViewer 참조)
- 제작 흐름: AI로 아이템 생성 → 배경 제거 → 1024 캔버스의 정위치에 정렬
  (앵커 수치 기준) → webp 변환 → `public/assets/avatar/<슬롯>/` 저장

## 3. 슬롯 구조 (탐험·베이커리 동일)

렌더 순서(뒤→앞): 배경 → **등 장비** → *(베이스 캐릭터)* → 신발 → 하의 → 상의
→ 목 장식·배지 → 얼굴 장식 → 모자 → 손 장비 → 효과

| 슬롯 key | 이름 | 비고 |
|---|---|---|
| background | 배경 | 프레임 전체 cover |
| back | 등 장비 | 캐릭터 **뒤**에 그려짐 (배낭·망토) |
| shoes | 신발 | |
| bottom | 하의 | |
| top | 상의 | 탐험 조끼·베이커리 앞치마 등 |
| neck | 목 장식·배지 | |
| face | 얼굴 장식 | 고글·안경 |
| hat | 모자 | |
| hand | 손 장비 | 손가락과 겹쳐야 해서 난이도 높음 — 후순위 |
| effect | 효과 | 맨 앞 |

## 4. 테마 구분 (장비 데이터 `theme` 필드)

`adventure`(탐험 전용) / `bakery`(베이커리 전용) / `common`(공용) / `seasonal`(시즌 전용)

## 5. 캐릭터 구분

- **성장 캐릭터 = 탐험가** (레벨 진화, 기존 시스템 유지)
- **꾸미기 캐릭터 = 아바타** (이 규격의 베이스 + 장비 레이어)
- 장비는 전부 **아바타 전용**으로 제작한다.

## 6. 초기 장비 6종 (탐험 테마 — 참조 아트: 완전무장 탐험가 일러스트)

| id | 슬롯 | 이름 | 가격 | 희귀도 |
|---|---|---|---|---|
| shoes_boots | shoes | 탐험 부츠 | 80 | 일반 |
| neck_scarf | neck | 빨간 스카프 | 90 | 일반 |
| face_goggles | face | 탐험 고글 | 120 | 레어 |
| top_vest | top | 탐험 조끼 | 150 | 레어 |
| hat_explorer | hat | 탐험 헬멧 | 200 | 에픽 |
| back_backpack | back | 탐험 배낭 | 250 | 에픽 |

6종 모두 장착하면 참조 아트(지도 든 탐험가)와 같은 "완전무장 탐험가"가 완성된다.
손 장비(지도)는 제작 난이도 문제로 v1 제외 → 목 장식(스카프)으로 대체.

## 7. 저장 키 (v2)

- 구 키 `v6_avatar_owned` / `v6_avatar_equipped` 는 **읽기 전용** (수정·삭제 금지)
- 마이그레이션: 구 보유 중 v2에도 있는 아이템(배경 3종)은 이전, 없어진 아이템은
