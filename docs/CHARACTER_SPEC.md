# 미션팡 캐릭터·장비 제작 규격 v2 (고정)

이 문서의 수치는 **고정 규격**이다. 캐릭터·장비 아트를 새로 만들 때 반드시 따른다.
2026-07-20 기준: **현재 실서비스의 아바타 표시 위치·크기를 확정 기준으로 채택**하고,
실제 탑재된 베이스 아트(`public/assets/avatar/base/default.webp`)를 픽셀 실측하여 수치를 검증·보강했다.

## 2. 인앱 표시 규격 (홈 화면) — 현재 확정 상태, 변경 금지

앱은 1024² 캔버스를 아래 크기의 정사각형으로 축소해 그대로 표시한다.
(레이어 전부 `inset:0 / 100%` 겹치기, 슬롯별 위치 보정 코드 없음 — `AvatarViewer.jsx`)

### 2-1. 모험 홈 (성장 단계별 아바타 정사각 크기)

`src/data/characters.js` — `AVATAR_HOME_SIZE`

| 성장 단계 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 정사각 한 변(px) | 289 | 300 | 309 | 316 | 325 |
| 화면상 캐릭터 키(×0.80) | 231 | 240 | 247 | 253 | 260 |

### 2-2. 베이커리 홈

정사각 한 변 = `BAKERY_CHAR_SIZE[단계] × 1.18`
(BAKERY_CHAR_SIZE = 232 / 248 / 264 / 270 / 282 → 274 / 293 / 312 / 319 / 333)

### 2-3. 레이아웃 상수와 파생 근거 (`App.jsx` 홈 무대)

| 상수 | 값 | 파생 근거 (캔버스 앵커 기준) |
|---|---|---|
| 실루엣 박스 폭 | 정사각 × **0.42** | 캐릭터 실폭 30% + 좌우 여유 |
| 실루엣 박스 높이 | 정사각 × **0.80** | 전체 키 820 ÷ 1024 ≈ 0.80 |
| 정사각 하단 내림 | 정사각 × **−0.08** | 발 아래 투명 여백 84px(1024−940) ÷ 1024 ≈ 0.08 → 발이 무대 바닥선에 접지 |
| 캐릭터 가로 위치 | 카드 **정중앙** | 펫은 우측 10% 절대배치로 분리 (2026-07-20 확정) |

## 3. 슬롯별 배치 구역 가이드 (베이스 아트 실측 기반, y좌표는 1024 캔버스 기준)

실측 부위 경계: 머리 최대폭 y=248 · 목 y≈400 · 몸통 최대폭 y=624 · 발끝 y=938

| 슬롯 | 배치 구역(세로) | 비고 |
|---|---|---|
| hat 모자 | y ≈ 60 ~ 300 | 머리 위로 살짝 돌출 가능, 폭 320~360px 권장 |
| face 얼굴 장식 | y ≈ 200 ~ 360 | 고글·안경 라인 y ≈ 280~310 |
| neck 목 장식 | y ≈ 380 ~ 470 | 목 잘록 지점 y ≈ 400 |
| top 상의 | y ≈ 400 ~ 700 | 어깨~허리 |
| bottom 하의 | y ≈ 620 ~ 800 | 허리~무릎 |
| shoes 신발 | y ≈ 780 ~ 940 | 발바닥 기준선 y = 940에 맞춤 |
| back 등 장비 | y ≈ 400 ~ 760 | 캐릭터 뒤 레이어, 어깨선 y ≈ 420 |
| hand 손 장비 | y ≈ 640 ~ 720, x ≈ 375 / 650 | 손가락 겹침 난이도 高 — 후순위 |

> 구역은 **가이드**(±30px 재량), 발바닥·중심·키 앵커는 **고정**이다.

## 4. 장비 제작 방식 (레이어 방식)

- 장비만 작게 잘라 저장하지 **않는다**.
- 캐릭터와 **동일한 1024×1024 캔버스**를 쓰고, 장비를 3장의 착용 구역에 놓은 뒤
  나머지 영역은 투명으로 저장한다.
- 앱은 캐릭터·장비 이미지를 **100% 크기로 그대로 겹쳐** 표시한다.
  (슬롯별 위치 보정 코드 없음 — AvatarViewer 참조)
- 제작 흐름: AI로 아이템 생성 → 배경 제거 → 1024 캔버스의 정위치에 정렬
  (1·3장 앵커 수치 기준) → webp 변환 → `public/assets/avatar/<슬롯>/` 저장

### 4-1. 제작물 검수 (탑재 전 필수)

```bash
python3 -c "
from PIL import Image
im=Image.open('파일.webp').convert('RGBA'); a=im.getchannel('A'); b=a.getbbox()
print('크기', im.size, '불투명 bbox', b)
# 베이스 캐릭터 합격 기준: 크기 (1024,1024) / 하단 935~945 / 좌우중심 508~516 / 키 810~830
"
```

### 4-2. 신발 슬롯 표준: '무릎 아래 통짜' 방식 (2026-07-20 확정)

- 신발 장비는 부츠만 오려 붙이지 않고, **착용 원화의 무릎 아래 전체**(정강이+양말+신발)를
  한 덩어리로 사용한다. 발목 이음새가 원화 그대로 이어져 합성 티가 나지 않는다.
- 절단선 y=760, 상단 페더 y760~800 (베이스 피부 위에서 알파 그라데이션).
- **가장자리 확장 금지**: 베이스 다리를 덮으려고 실루엣 밖으로 색을 늘리면
  어두운 배경에서 얼룩 테두리가 생긴다(2026-07-20 사고 사례). 1~2px 어긋남은 그대로 둔다.
- 제작은 반드시 **원본에서 원패스**(배경제거→defringe→정렬→절단)로 하고,
  중간 산출물 재가공 금지. 저장은 **무손실 WebP**.
- 탑재 전 **남색 배경(#1E2D50) 2배 확대 검수** 필수 — 밝은 배경에서 안 보이던
  흰 보풀·얼룩이 실서비스 배경에서 드러난다.

## 5. 슬롯 구조 (탐험·베이커리 동일)

렌더 순서(뒤→앞): 배경 → **등 장비** → *(베이스 캐릭터)* → 신발 → 하의 → 상의
→ 목 장식·배지 → 얼굴 장식 → 모자 → 손 장비 → 효과

| 슬롯 key | 이름 | 비고 |
|---|---|---|
| background | 배경 | 프레임 전체 cover |
| back | 등 장비 | 캐릭터 **뒤**에 그려짐 (배낭·망토) |
| shoes | 신발 | |
| bottom | 하의 | |
| top | 상의 | 탐험 조끼·베이커리 앞치마 등 |
| neck | 목 장식·배지 | |
| face | 얼굴 장식 | 고글·안경 |
| hat | 모자 | |
| hand | 손 장비 | 손가락과 겹쳐야 해서 난이도 높음 — 후순위 |
| effect | 효과 | 맨 앞 |

## 6. 테마 구분 (장비 데이터 `theme` 필드)

`adventure`(탐험 전용) / `bakery`(베이커리 전용) / `common`(공용) / `seasonal`(시즌 전용)

## 7. 캐릭터 구분

- **성장 캐릭터 = 탐험가** (레벨 진화, 기존 시스템 유지)
- **꾸미기 캐릭터 = 아바타** (이 규격의 베이스 + 장비 레이어)
- 장비는 전부 **아바타 전용**으로 제작한다.

## 8. 초기 장비 6종 (탐험 테마 — 참조 아트: 완전무장 탐험가 일러스트)

| id | 슬롯 | 이름 | 가격 | 희귀도 |

6종 모두 장착하면 참조 아트(지도 든 탐험가)와 같은 "완전무장 탐험가"가 완성된다.
손 장비(지도)는 제작 난이도 문제로 v1 제외 → 목 장식(스카프)으로 대체.

## 9. 저장 키 (아바타 장비 2세대 체계)

2세대로 개편되어 키 이름 끝에 `2`가 붙는다. (v6_ 접두사 ≠ 체계 버전)

- 신규 키: `v6_avatar_owned2` / `v6_avatar_equipped2`
