# 미션팡 — 구글 플레이 등록 준비 (2026-10-30)

Play Console에 그대로 옮겨 적을 수 있게 정리한 문서. 앱 동작이 바뀌면(서버·광고·분석 추가 등) **데이터 보안·개인정보처리방침을 함께 고친다.**

## 1. 개인정보처리방침
- 파일: `public/privacy.html` → 배포 후 주소 `https://<배포 도메인>/privacy.html`
- Play Console → 앱 콘텐츠 → 개인정보처리방침에 위 주소를 넣는다.
- 문의처는 앱의 '버그 신고' 카카오톡 오픈채팅. 이메일을 함께 적고 싶으면 7번 항목에 추가한다.

## 3. 앱 콘텐츠 설문 답안
### 데이터 보안
- 앱이 필수 사용자 데이터 유형을 **수집하거나 공유하나요? → 아니요**
  - 근거: 서버 전송·광고·분석 SDK 없음. 모든 데이터는 기기 저장소(Capacitor Preferences/localStorage).
  - 백업은 사용자가 공유창에서 직접 보낼 곳을 고르는 것이라 '앱이 수집'에 해당하지 않는다.
  - 외부 링크(네이버 지도·카카오 오픈채팅)·전화/문자는 다른 앱을 여는 것뿐, 앱이 데이터를 보내지 않는다.
- (수집 없음으로 답하면 암호화·삭제 요청 질문은 나오지 않는다)

### 광고
- 앱에 광고가 있나요? → **아니요**

### 앱 액세스 권한
- 모든 기능을 별도 로그인 없이 쓸 수 있나요? → **예** (보호자 비밀번호는 사용자가 앱 안에서 직접 만드는 것이라 심사용 계정 불필요)
  - 메모란 예: "첫 실행 시 보호자가 4자리 비밀번호를 직접 정합니다. 계정·로그인은 없습니다."

### 콘텐츠 등급 (IARC 설문)
- 폭력·선정성·욕설·약물·도박: 모두 **없음**
- 사용자 간 소통/채팅: **없음** (앱 안에 채팅 없음 — 카카오 오픈채팅은 외부 앱, 보호자 비밀번호 뒤)
- 위치 공유·개인정보 공유: **없음**
- 디지털 상품 구매: **없음** (코인은 미션으로만 얻는 게임 안 화폐, 실제 결제 없음)
- 예상 등급: 전체이용가

### 타겟층 및 콘텐츠
- **추천: 타겟 연령에 '5세 이하·6~8세·9~12세'와 '18세 이상'을 함께 선택** (아이 화면이 있으므로 13세 미만 포함으로 신고하는 쪽이 안전)
  - 13세 미만을 포함하면 **가족 정책**이 적용된다. 현재 앱이 이미 맞춘 부분:
    - 광고·분석 SDK 없음
    - 앱 밖 링크(카카오 오픈채팅·네이버 지도)는 보호자 비밀번호 뒤 (#1044)
    - 개인정보처리방침 있음
  - 질문 "앱이 아동에게 의도치 않게 매력적일 수 있나요?"는 아동을 포함해 선택하면 나오지 않는다.
- 18세 이상만 선택하면 정책은 가볍지만, 아이 화면 때문에 심사에서 반려될 수 있다.
